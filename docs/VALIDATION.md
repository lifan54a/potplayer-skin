# 验收清单

## 已自动检查

- 各素材引用与包含文件存在。
- 视频/音频的布局标签成对闭合。
- 四个布局均保留原来的 65 像素底栏。
- 时间、倍速、进度条、总时长在最小 350 像素宽度下不重叠。
- 倍速读取与增减、恢复正常命令均存在。
- DSF 直接包含布局文件，没有多套目录。
- 每个封装条目都能读取。
- 调色前后逐像素检查 PNG 尺寸、DPI、透明度位置和非目标区域。
- 四套布局各检查 240–1920 像素中的 18 个边界案例；倍速不得超出播放控制行，普通按钮不得重叠。

## v1.0.2 已实机检查

使用 640×360、120 秒纯色本地测试片。以下均在用户当前 Windows / PotPlayer 环境完成，未改系统 DPI。

- [x] 350 像素可用宽度：播放与倍速控件完整，没有侵入画面。
- [x] 640 像素可用宽度：紧凑布局、时间、音量与速度各自留有空间。
- [x] 960 像素可用宽度：播放组居中，速度与设置按钮同排。
- [x] 播放列表打开、关闭后底栏正常。
- [x] 视频暂停时倍速保持可见。
- [x] 点击加速从 1× 变为 1.1×，点击当前倍速恢复 1×。
- [x] 纯色画面止于底栏上方，速度按钮不与视频区域重叠。

实际效果见 [小窗](small-window.png) 与 [宽窗](wide-window.png)。240–349 像素的极窄分支目前仅做几何自动检查，未在本次实际窗口中触发。

v1.0.0 的文件结构检查没有覆盖图片重绘导致的图集坐标变化，这一遗漏已在 v1.0.1 的构建阶段修正。当前不将逐像素检查表述为播放器实机验收。
